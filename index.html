Plotly.js Custom Marker Functions

Demos for the custom marker functions feature that allows passing JavaScript functions directly as marker.symbol values.

  • Weather Map Demo

    Data-driven markers: sun, cloud, and wind barb symbols based on customdata

  • Custom Marker Demo

    Simple custom shapes: heart and star markers using only radius

  • Backward Compatibility Test

    Shows both simple (r) and data-aware (r, d, trace) functions working together
